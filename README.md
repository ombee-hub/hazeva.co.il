# מושב חצבה – אתר האינטרנט

אתר סטטי של מושב חצבה בערבה התיכונה. נבנה מחדש על בסיס התוכן של האתר הישן (hazeva.co.il/oldsite).

עיצוב ובנייה: [OMBee](https://ombee.co.il)

## מבנה התיקייה

| נתיב | תוכן |
|---|---|
| `*.html` | 42 דפי האתר. **נוצרים אוטומטית** – לא עורכים אותם ישירות |
| `assets/site.css` | כל העיצוב של האתר |
| `assets/site.js` | תפריט מובייל, גלריה, טופס יצירת קשר, תו נגישות, הודעת עוגיות |
| `images/` | כל התמונות, בפורמט WebP, בשמות לפי תחום (`gallery-`, `history-`, `stay-`, `business-` וכו') |
| `tools/build.mjs` | סקריפט הבנייה – מכיל את כל התוכן והתבניות של הדפים |

## עדכון תוכן

כל הטקסטים, פרטי הקשר והתבניות נמצאים ב-`tools/build.mjs`. אחרי שינוי בו, בונים מחדש את הדפים:

```
node tools/build.mjs .
```

שינוי בעיצוב או בהתנהגות (`assets/site.css`, `assets/site.js`) לא דורש בנייה מחדש.

להוספת תמונה: שומרים אותה בתיקייה `images` כקובץ `.webp`, ומפנים אליה מ-`tools/build.mjs`.
